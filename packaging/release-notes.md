**Canopy Pads 1.0** — ambient drone pads for church musicians, by John Carl Tagbor.

**Download:** `…-mac.dmg` (Apple Silicon + Intel, macOS 11+) or `…-windows-setup.exe` (Windows 10/11 64-bit). Installs the standalone app plus the AU (MainStage / Logic) and VST3 (Ableton, Studio One, Reaper…) plugins.

> Mac: this is an unsigned community build, so the first time macOS will say it can't verify the developer — right-click the installer → Open → Open.

**In this release**
- One-key latching drones with smooth crossfades
- Root / Major / Minor / Chord-follow modes
- 8 pad engines (Warm, Shimmer, Dark, Glass, Choir, Strings, Organ, Ocean) + Sub, 3 layers deep
- Load your own WAV/MP3 pads per key, auto-transposed
- Swell control for expression pedals, 3-band EQ, reverb, brightness, motion, width
- Setlists with footswitch Next/Prev, full MIDI learn, sustain-pedal hold, laptop-keyboard control
- Export any key or all 12 as WAV pad files

Full guide: https://github.com/jctagbor/canopy-pads#readme
